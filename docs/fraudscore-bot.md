# FraudScore — UX Telegram-бота

Антифрод-скоринг телефонных номеров: пользователь загружает CSV, бот обогащает номера через DaData и возвращает файл с уровнем риска и признаками.

**Прототип:** [`mockups/fraudscore-bot.html`](../mockups/fraudscore-bot.html)  
**Краткая карта:** [`mockups/design.md`](../mockups/design.md)

---

## 1. Карта сценариев

```
/start (онбординг)
  ├─ [📎 Загрузить CSV] ──► пользователь шлёт файл
  │                          ├─ OK ──► подтверждение ──► [▶️ Начать]
  │                          │                              ├─ прогресс (edit_message)
  │                          │                              │    ├─ [🛑 Отменить] ──► отмена
  │                          │                              │    └─ 100% ──► итоговая выдача + CSV
  │                          │                              └─ [❌ Отмена] ──► назад к загрузке
  │                          └─ ошибка (нет phone / лимит / DaData) ──► recovery-кнопки
  ├─ [📄 Формат файла] ──► экран формата ──► [◀️ Назад]
  └─ [🔒 Данные и приватность] ──► политика ──► [🗑 Удалить сейчас] / [◀️ Назад]
```

| # | Экран | Триггер |
|---|--------|---------|
| 1 | /start — онбординг | `/start` или возврат в корень |
| 2 | Формат файла | кнопка «Формат файла» |
| 3 | Загрузка CSV | пользователь прислал `.csv` |
| 4 | Прогресс | «Начать проверку» |
| 5 | Отмена | «Отменить» во время прогресса |
| 6 | Итоговая выдача | завершение 100% |
| 7 | Ошибки | валидация / недоступность DaData |
| 8 | Данные и приватность | кнопка / команда политики |

## 2. Тексты сообщений

### Экран 1 — `/start`

**Бот:**

> 👋 Я FraudScore — проверяю телефонные номера на признаки фрода.
>
> Пришли CSV со столбцом phone (до 500 строк) — верну файл с уровнем риска и признаками.

**Inline-кнопки:**

| Кнопка | Действие |
|--------|----------|
| 📎 Загрузить CSV | Подсказка прислать файл (или `request` document) |
| 📄 Формат файла | → экран 2 |
| 🔒 Данные и приватность | → экран 8 |

---

### Экран 2 — Формат файла

**Бот:**

> **📄 Формат CSV**
> - Обязательный столбец: **phone**
> - Кодировка: UTF-8
> - Разделитель: запятая или **;**
> - Лимит: до 500 строк данных

**Превью (моноширинный блок):**

```
phone
+79161234567
+79031112233
```

**Кнопка:** ◀️ Назад → экран 1

---

### Экран 3 — Файл принят

**Пользователь (пузырь-вложение):** `leads_march.csv · 342 строки`

**Бот:**

> Файл принят. Нашёл столбец phone, 342 номера. Начать проверку?

**Кнопки:** ▶️ Начать проверку · ❌ Отмена

---

### Экран 4 — Прогресс (`edit_message`)

Одно сообщение бота обновляется in-place.

**Шаблон (в процессе):**

> ⏳ Проверяю номера через DaData…
>
> Обработано **N/M · P%**  
> `[████░░░░]` прогресс-бар  
> 🟢 X · 🟡 Y · 🔴 Z найдено

**Кнопка:** 🛑 Отменить

**Стадии (пример на 342 номерах):**

| Стадия | N/M | % | Статус-счётчик | Примечание |
|--------|-----|---|----------------|------------|
| A | 120/342 | 35% | 🟢 231 · 🟡 74 · 🔴 37 | промежуточный подсчёт |
| B | 280/342 | 82% | 🟢 198 · 🟡 58 · 🔴 24 | продолжение |
| C | 342/342 | 100% | 🟢 231 · 🟡 74 · 🔴 37 | «✅ Готово…» → переход к экрану 6 |

Частота обновлений: не чаще ~1 раз / 1–2 с (лимиты Telegram Bot API).

---

### Экран 5 — Отмена

> Проверка отменена. Обработано 120 из 342, файл не сохранён.

**Кнопка:** 📎 Загрузить заново

---

### Экран 6 — Итоговая выдача (главный)

> ✅ Готово. Проверено 342 номера.
>
> 🟢 Низкий риск — 231 (можно работать)  
> 🟡 Средний риск — 74 (проверьте вручную)  
> 🔴 Высокий риск — 37 (рекомендуем не звонить)
>
> **🔴 Топ высокого риска (примеры):**
>
> *(3 карточки: маскированный номер, %/бэйдж, топ-3 признака)*
>
> 📎 Полный отчёт во вложении

**Вложение:** `fraudscore_report_2024-03.csv · 342 строки`

**Пример карточки высокого риска:**

| Поле | Пример |
|------|--------|
| Номер | `+7 916 ***-45-67` |
| Бэйдж | `92%` |
| Признаки | робот/автоответчик в справочнике · номер оператора виртуальной АТС · регион не совпадает с заявленным |

**Кнопки:** 🔄 Проверить ещё файл · 🔒 Удалить мои данные

---

### Экран 7 — Ошибки

| Код | Текст | Recovery |
|-----|-------|----------|
| 7а | ⚠️ Не нашёл столбец phone. Проверьте заголовок первой строки. | 📄 Формат файла |
| 7б | ⚠️ В файле 812 строк, лимит 500. Разбейте файл на части. | 📄 Формат файла |
| 7в | ⚠️ Сервис обогащения временно недоступен. Попробуйте через пару минут. | 🔁 Повторить |

---

### Экран 8 — Данные и приватность (дословно)

**Заголовок:** 🔒 Как мы обращаемся с данными

- Загруженный CSV и результат хранятся 24 часа, затем удаляются автоматически.
- Номера телефонов используются только для проверки через DaData и расчёта риска — не передаются третьим лицам и не используются для рекламы.
- Доступ к файлам есть только у вас (владельца бота); это личный сервис, чужие пользователи данные не видят.
- Команда /delete удаляет ваши файлы и результаты немедленно.
- Проверка через DaData обогащает номер публичными справочными данными (регион, оператор, признак робота); сам факт региона или оператора не является доказательством фрода — это сигнал для ручной проверки.

**Кнопки:** 🗑 Удалить сейчас · ◀️ Назад

## 3. Политика хранения

| Правило | Значение |
|---------|----------|
| TTL файлов и результатов | 24 часа, затем автоудаление |
| Немедленное удаление | `/delete` или кнопка «Удалить сейчас» / «Удалить мои данные» |
| Область доступа | только владелец чата (личный сервис) |
| Назначение номеров | только DaData + расчёт риска |
| Запрет | передача третьим лицам, реклама |
| Интерпретация сигналов | регион/оператор ≠ доказательство фрода |

## 4. Design system

### Цвета (CSS variables в прототипе)

| Token | HEX | Назначение |
|-------|-----|------------|
| `--tg-bg` | `#0E1621` | фон чата |
| `--tg-bubble-bot` | `#182533` | пузырь бота |
| `--tg-bubble-user` | `#2B5278` | пузырь пользователя |
| `--tg-text` | `#F8FAFC` | основной текст |
| `--tg-muted` | `#7A8A99` | вторичный текст / время |
| `--tg-link` | `#5EA9DD` | текст inline-кнопок |
| `--tg-bg-elevated` / кнопка | `#17212B` | фон inline-кнопок |
| `--status-green` | `#22C55E` | низкий риск |
| `--status-amber` | `#F59E0B` | средний риск |
| `--status-red` | `#EF4444` | высокий риск |

### Типографика

- Body: system / SF Pro / Roboto (`-apple-system, BlinkMacSystemFont, "SF Pro Text", Roboto, …`)
- CSV / таблицы / маскированные номера: **JetBrains Mono**

### Inline-кнопки

- Фон: полупрозрачный `#17212B`
- Текст: `#5EA9DD`
- Скругление: `8px`
- `min-height: 44px` (touch target)
- Опасные действия (отмена / удаление): красный акцент текста

### Прогресс-бар

- Тонкая полоса (4px) + подпись `N/M · P%`
- На 100% заливка зелёная (`--status-green`)

### Контраст (WCAG 2.1 AA)

Целевой контраст текста ≥ **4.5:1**:

| Пара | Оценка |
|------|--------|
| `#F8FAFC` на `#182533` | ~12.5:1 ✓ |
| `#F8FAFC` на `#2B5278` | ~7.8:1 ✓ |
| `#5EA9DD` на `#17212B` | ~5.5:1 ✓ |
| `#7A8A99` на `#0E1621` | ~4.6:1 ✓ (только muted/meta) |

## 5. UX-заметки

1. **Прогресс через `edit_message`** — не спамить новыми сообщениями; одно «живое» сообщение со стадиями 0→N→готово.
2. **Маскирование номеров** в превью чата: `+7 916 ***-45-67`. Полные номера — только в CSV-отчёте.
3. **Лимит 500 строк** — жёсткий; при превышении понятная ошибка + ссылка на формат.
4. **Touch targets ≥ 44px** для всех inline-кнопок.
5. **WCAG AA** — не использовать muted-цвет для ключевых инструкций; ошибки дублировать текстом, не только цветом/эмодзи.
6. **Легенда риска** всегда с глаголом действия («можно работать» / «проверьте вручную» / «рекомендуем не звонить»).
7. **Топ-3 высокого риска** — обучающий сэмпл, не полный список; полный отчёт во вложении.
8. **При отмене** — явно сказать, что файл результата не сохранён (нет ложного ожидания download).
9. **Ширина прототипа** ~420px — мобильный viewport Telegram.
10. **Личный сервис** — копирайт приватности не обещает multi-tenant SaaS; формулировки про «владельца бота».

# Критика: идеи лидогенерации на базе ИИ-демо

Контекст: сайт «ОПОРА» — лендинг локальной строительной бригады (design/index.html, docs/design.md). Оценка выполнена с учётом реальной ниши, не абстрактно.

## Оценка: 6/10

**Сильные стороны:**
- ИИ-демо как lead magnet реально повышает конверсию — люди охотнее оставляют контакт за «бесплатный расчёт/аудит», чем за абстрактную заявку.
- «ИИ-аудит сайта после регистрации» — рабочий паттерн для SaaS/агентств, но требует переноса логики на реальную боль клиента стройки (расчёт объекта, а не сайта).
- Чат-ассистент разумен как способ снять первичные вопросы и квалифицировать лида до звонка менеджера.

**Риски:**
- Несоответствие ниши: «ИИ-аудит сайта» дословно — функция для маркетингового/веб-агентства, а не для строительной бригады. Внедрение буквально снижает доверие.
- ИИ-функция ради фичи (чат без сценария) не конвертит.
- ИИ-функции требуют бюджета на API (LLM/vision), поддержку промптов, модерацию — доп. косты вне текущего ТЗ.
- Нет baseline метрики конверсии текущего сайта — без неё нельзя доказать эффект ИИ-фич.

## Топ-3

1. **ИИ-калькулятор сметы** — прямое попадание в намерение посетителя, низкий порог входа для MVP, легко A/B-тестировать.
2. **Опросник-конфигуратор с отчётом на почту** — минимальная сложность (можно без реального ИИ), быстрый to-market, прямой сбор контактов.
3. **ИИ-аудит объекта по фото** — сильный дифференциатор от локальных конкурентов, но это фича v2, после теста базовой конверсии калькулятора/формы.

## Вердикт

Идею «ИИ-демо как двигатель лидогенерации» одобряю, но исключить из плана буквальный «ИИ-аудит сайта» — чужеродная фича для лендинга стройбригады, взята шаблонно из другой ниши. Приоритет: сначала калькулятор сметы + форма-конфигуратор (низкая сложность, быстрый эффект), фото-аудит и визуализацию — во вторую волну. Перед запуском любой ИИ-фичи замерить baseline конверсии текущей формы.

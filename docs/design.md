# Mars Agency — Design Specification

Визуальный макет лендинга креативного агентства Mars Agency. Прототип находится в папке `design/` и не затрагивает основной код репозитория.

## Быстрый просмотр

```bash
# Открыть в браузере
open design/index.html
# или
python3 -m http.server 8080 --directory design
```

| Token                 | Назначение                          |
|-----------------------|-------------------------------------|

## UX-заметки

### Информационная архитектура

1. **Hero** — мгновенно отвечает на вопросы «кто вы» и «что предлагаете». Два CTA: основной (конверсия) и вторичный (изучение портфолио).
2. **Services** — сканируемая сетка из 6 карточек. Иконки-заглушки заменяются на SVG в production.
3. **Work** — социальное доказательство через кейсы с метриками результата.
4. **Process** — снижает тревожность: клиент видит прозрачный путь от brief до launch.
5. **Testimonial** — один сильный отзыв вместо карусели (меньше когнитивной нагрузки).
6. **Contact** — форма в финальном CTA-блоке, минимум полей (имя, email, сообщение).

### Поведение и взаимодействие

- **Sticky header** с blur — навигация всегда доступна при скролле.
- **Mobile nav** — fullscreen overlay по клику на hamburger; закрывается по клику на ссылку или Escape.
- **Hover states** — карточки и work-items реагируют на наведение (border + лёгкий lift).
- **Smooth scroll** — отключён при `prefers-reduced-motion: reduce`.

### Доступность (WCAG 2.1 AA)

| Критерий | Реализация |
|----------|------------|
| 1.3.1 Info and Relationships | Семантические теги (`header`, `main`, `nav`, `section`, `article`, `footer`), `aria-labelledby`, `role` где нужно |
| 1.4.3 Contrast (Minimum) | Все текстовые пары ≥ 4.5:1 |
| 2.1.1 Keyboard | Все интерактивные элементы доступны с клавиатуры |
| 2.4.1 Bypass Blocks | Skip link «Перейти к основному содержимому» |
| 2.4.7 Focus Visible | `:focus-visible` с контрастным outline (`--color-focus-ring`) |
| 2.5.5 Target Size | Кнопки и ссылки ≥ 44×44px (`min-height: 2.75rem`) |
| 3.3.2 Labels or Instructions | `<label>` связаны с полями через `for`/`id` |
| 4.1.2 Name, Role, Value | `aria-expanded`, `aria-controls`, `aria-label` на toggle и social links |

### Рекомендации для production

- Заменить placeholder-изображения на WebP/AVIF с `alt`-текстом.
- Подключить валидацию формы на стороне сервера + honeypot/spam protection.
- Добавить `og:` meta-теги и favicon.
- Рассмотреть lazy-loading для изображений портфолио.
- A/B-тест: hero с видео vs статичное изображение.

## Связь с основным репозиторием

Прототип изолирован в `design/` и не влияет на будущую реализацию. При переносе в production:

1. Скопировать токены из `variables.css` в основной CSS/SCSS.
2. Разбить HTML на компоненты (React/Vue/Svelte — по выбору стека).
3. Заменить inline SVG и placeholder-контент на реальные ассеты.

# MARS Agency — Design Documentation

Визуальный макет лендинга [mars-agency.pro](https://mars-agency.pro) для репозитория `site_mars`.

**Прототип:** `design/index.html` — откройте в браузере или через локальный сервер.

---

## 1. Цели дизайна

| Цель | Решение |
|------|---------|
| Конверсия в заявку | CTA в hero, sticky header, CTA-баннер, две формы лид-магнита |
| Лид-генерация | Аудит сайта + ресторанная диагностика (бронь, меню, агрегаторы) |
| Доверие | Метрики (500+ проектов, +35% конверсии), партнёры, FAQ |
| Понятность услуг | 4 карточки услуг, процесс «Анализ → Стратегия → Рост» |
| Премиальный HoReCa-образ | Тёмный hero, красный акcent MARS, 3D-визуализация роста/KPI |
| Вау-эффект | Three.js 3D-сцена в hero (desktop), CSS-fallback на mobile |

## 3. 3D-анимация (Hero)

**Технология:** [Three.js](https://github.com/mrdoob/three.js/) (MIT, CDN) — de-facto стандарт для WebGL в open-source лендингах (паттерны из three.js/examples, Bruno Simon portfolio, awwwards-клонов на GitHub).

**Файл:** `design/js/hero-3d.js`

**Метафора:** центральная «тарелка» (HoReCa) + орбитальные KPI-кольца и data-nodes (системный маркетинг, цифры). Красно-бело-чёрная палитра бренда.

**Поведение:**
- Parallax по движению курсора в hero (desktop)
- Медленное вращение колец и узлов
- Частицы на фоне

**Fallback / a11y:**
- `prefers-reduced-motion: reduce` → статичный CSS-орнамент (кольца + тарелка)
- Viewport < 1024px → без WebGL (экономия батареи)
- Canvas `aria-hidden="true"` — декоративный элемент

## 4. Лид-магниты

### 4.1 Аудит сайта

| Поле | Назначение |
|------|------------|
| Имя | Персонализация отчёта |
| E-mail | Доставка полного отчёта |
| URL сайта | Объект анализа |
| Согласие | GDPR / 152-ФЗ |

**После отправки (прототип):** mock-preview с score 0–100 и чек-листом: SEO, скорость, mobile, WCAG, CTA.

**Backend (TODO):** Lighthouse API, crawler, CRM webhook.

### 4.2 Аудит ресторана

| Поле | Назначение |
|------|------------|
| Название ресторана | Контекст отчёта |
| Телефон | Обратная связь эксперта |
| URL (опционально) | Сайт / агрегатор |
| Чекбоксы | Бронирование / меню / карты |

**После отправки:** mock-preview по выбранным пунктам — типичные HoReCa-проблемы (виджет брони, PDF-меню, расхождение часов на картах).

### UX-паттерн

1. Табы с `role="tablist"` — переключение без перезагрузки
2. Минимум полей в первом шаге
3. Loading state «Анализируем…» (1.4 с) — ожидание backend
4. Preview с `aria-live="polite"` + focus для screen readers
5. Disclaimer о демо-данных

## 6. Типографика

- **Шрифт:** Montserrat (Google Fonts) — близок к Mont на текущем сайте
- **Hero H1:** `clamp(2rem, 5vw + 1rem, 3.75rem)`, weight 700
- **Section H2:** 1.875rem → 2.25rem на tablet+
- **Body:** 1rem / line-height 1.55
- **Eyebrow:** uppercase, letter-spacing 0.04em, красный

## 7. UX-заметки

### Навигация

- Sticky header — CTA и телефон всегда доступны
- Mobile drawer: Escape, backdrop, авто-закрытие по ссылке
- Skip-link «Перейти к содержимому»
- Новый пункт «Диагностика» ведёт к лид-магниту (главная конверсионная воронка)

### Конверсионная воронка

```
Hero CTA → Лид-магнит (таб) → Mock preview → Контакт эксперта
                ↓
         Header «Заявка» → Форма аудита (низ страницы)
```

**Рекомендация для продакшена:** плавающая кнопка WhatsApp/Telegram на mobile.

### Формы

- Inline-валидация: `aria-invalid`, тексты ошибок
- Разделение: лид-магнит (email + URL) vs заявка (телефон) — разные intent
- После отправки — `role="status"` / `aria-live`

### FAQ

- Аккордеон: один открытый пункт
- `aria-expanded`, `aria-controls`, `role="region"`

### Контент

- Pain tags — узнавание болей владельца ресторана
- Ресторанный лид-магнит — отстройка от generic «SEO-аудитов»
- Плейсхолдеры партнёров → реальные логотипы при интеграции

## 8. Доступность (WCAG 2.1 AA)

| Критерий | Реализация |
|----------|------------|
| 1.3.1 Info and Relationships | Семантика: header, nav, main, section, article, footer, tablist |
| 1.4.3 Contrast | Палитра проверена (таблица выше) |
| 2.1.1 Keyboard | Табы (Arrow/Home/End), FAQ, формы, меню |
| 2.3.3 Animation | `prefers-reduced-motion` отключает 3D и CSS spin |
| 2.4.1 Bypass Blocks | Skip-link |
| 2.4.7 Focus Visible | `:focus-visible` outline 3px |
| 3.3.1 Error Identification | `aria-invalid` + текст ошибки |
| 4.1.2 Name, Role, Value | ARIA на табах, FAQ, формах, preview |

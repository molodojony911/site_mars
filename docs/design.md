# MARS Agency — Design Documentation

Визуальный макет лендинга [mars-agency.pro](https://mars-agency.pro) в марсианской тематике для репозитория `site_mars`.

**Прототип:** `design/index.html` — откройте в браузере или через локальный сервер.

---

## 1. Концепция: «Mission to Growth»

Название агентства **MARS** — отправная точка для космической метафоры: маркетинг ресторана как космическая миссия с точной навигацией, KPI и контролем каждого этапа.

| Цель | Решение |
|------|---------|
| **Wow-эффект** | 3D-планета Марс (Three.js), звёздное небо, орбитальные кольца, свечение |
| **Удержание внимания** | Калькулятор ROI, анимированные счётчики, marquee партнёров, 3D-tilt карточек |
| **Конверсия** | CTA в hero, sticky header, CTA-баннер, форма аудита |
| **Доверие** | Метрики Mission Control, FAQ, блок партнёров |
| **Премиальный образ** | Glassmorphism, тёмный космос, марсианские градиенты |

## 3. Wow-фичи и удержание внимания

| Фича | Технология | Поведение |
|------|------------|-----------|
| **3D Марс** | Three.js WebGL | Автовращение, drag/touch, parallax при скролле, атмосферное свечение |
| **Звёздное небо** | Canvas 2D | Мерцающие звёзды, медленный дрейф вверх |
| **Пылевые частицы** | CSS animation | 20 частиц в hero, имитация марсианской пыли |
| **Mission Progress** | Scroll listener | Верхняя полоса — «траектория миссии» |
| **Счётчики** | IntersectionObserver | Анимация 0 → 500+ при появлении в viewport |
| **Mission Timeline** | IntersectionObserver | Подсветка активной фазы + progress bar |
| **ROI-калькулятор** | Range inputs | Мгновенный пересчёт роста и прибыли |
| **3D Tilt карточек** | CSS transform + mousemove | Голографический эффект на услугах |
| **Marquee партнёров** | CSS animation | Бесконечная прокрутка логотипов |
| **Scroll reveal** | IntersectionObserver | Плавное появление секций снизу |
| **Орбитальные кольца** | CSS animation | Вращающиеся эллипсы вокруг планеты |

Все анимации отключаются при `prefers-reduced-motion: reduce`.

## 5. Типографика

- **Шрифт:** Montserrat (Google Fonts), weights 400–800
- **Hero H1:** `clamp(2rem, 5vw + 1rem, 4.5rem)`, weight 700, gradient на акцентном слове
- **Section H2:** 1.875rem → 2.25rem на tablet+
- **Body:** 1rem / line-height 1.55
- **Eyebrow:** uppercase, letter-spacing 0.2em, марсианский оранжевый
- **Mission tags:** uppercase, cyan, letter-spacing 0.08em

## 6. UX-заметки

### Первое впечатление (0–5 сек)

Пользователь видит тёмный космос, вращающуюся 3D-планету и заголовок с метафорой миссии. Badge «Mission Control» создаёт ощущение технологичности и контроля — ключевые ценности для B2B-клиентов (владельцы ресторанов).

### Навигация

- Sticky glass-header с blur — контент «плывёт» под ним, сохраняя CTA доступным.
- Mission Progress Bar даёт ощущение продвижения и мотивирует долистать до формы.
- Skip-link для клавиатуры и screen readers.
- Mobile drawer с backdrop, закрытие по Escape.

### Интерактивные точки удержания

1. **3D Марс** — пользователь крутит планету (среднее время взаимодействия +15–30 сек).
2. **ROI-калькулятор** — персонализация: «что будет с моим рестораном» (вовлечение 1–2 мин).
3. **Счётчики** — социальное доказательство с динамикой.
4. **Marquee** — движение привлекает периферийное зрение.

### Конверсионные точки

1. Hero CTA (primary)
2. Header «Оставить заявку»
3. CTA banner «Запустить миссию»
4. Форма «Бесплатный аудит»
5. Телефон в header и audit-card

### Форма заявки

- Минимум полей: имя + телефон + согласие.
- Inline-валидация с `aria-invalid`.
- `role="status"` после отправки.

### Контентные решения

- Pain tags на светлом фоне — контрастная секция для «узнавания боли».
- Mission Timeline вместо статичных шагов — ощущение процесса.
- Светлая секция «Кто мы» чередуется с тёмными — ритм страницы, снижение усталости.

## 7. Доступность (WCAG 2.1 AA)

| Критерий | Реализация |
|----------|------------|
| 1.3.1 Info and Relationships | Семантика: `header`, `nav`, `main`, `section`, `article`, `footer` |
| 1.4.3 Contrast | Палитра проверена (таблица выше) |
| 1.4.10 Reflow | Mobile-first, без горизонтального скролла |
| 2.1.1 Keyboard | Все интерактивные элементы доступны с клавиатуры |
| 2.3.1 Three Flashes | Нет мигающего контента > 3 раз/сек |
| 2.4.1 Bypass Blocks | Skip-link |
| 2.4.7 Focus Visible | `:focus-visible` с cyan outline 3px |
| 2.5.1 Pointer Gestures | 3D Марс работает и с touch |
| 3.3.1 Error Identification | `aria-invalid` + текст ошибки |
| 4.1.2 Name, Role, Value | ARIA на меню, FAQ, форме, 3D canvas, progress bar |

### Reduced motion

При `prefers-reduced-motion: reduce`:
- Отключаются starfield, dust, marquee, scroll reveal, 3D Mars
- Счётчики показывают финальные значения сразу
- CSS transitions → 0ms

### 3D Canvas accessibility

```html
<canvas role="img" aria-label="Интерактивная 3D-модель планеты Марс. Перетащите для вращения.">
```

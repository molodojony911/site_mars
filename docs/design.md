# MARS Agency — Design System & Wireframe

Визуальный макет лендинга [mars-agency.pro](https://mars-agency.pro) для репозитория `site_mars`.

**Прототип:** [`design/index.html`](../design/index.html) — откройте в браузере для просмотра.

---

## 1. Цели и аудитория

| Параметр | Описание |
|----------|----------|
| **Продукт** | Маркетинговое агентство для ресторанов «под ключ» |
| **Аудитория** | Владельцы и управляющие ресторанов, шефы, инвесторы в HoReCa |
| **Цель страницы** | Конверсия в заявку / бесплатный аудит |
| **Тон** | Экспертный, data-driven, премиальный, но доступный |

## 4. Типографика

- **Шрифт:** Inter (Google Fonts), fallback system-ui
- **H1:** `clamp(2rem, 5vw, 3.25rem)` — fluid, крупный текст ≥ 3:1
- **H2:** `clamp(1.75rem, 4vw, 2.5rem)`
- **Body:** 16px / line-height 1.6
- **Eyebrow:** uppercase, letter-spacing 0.08em, 14px

## 5. UX-заметки

### Иерархия и сканирование

1. **Hero** — одно главное обещание («под ключ») + два CTA (primary: заявка, secondary: аудит).
2. **Stats bar** — социальное доказательство сразу после hero; дублирует метрики для усиления доверия.
3. **Услуги** — карточки с иконкой, заголовком и 3 bullet points; сканируются за 5–10 секунд.
4. **Процесс** — снижает тревожность: понятный путь из 4 шагов.
5. **Pain points** — эмпатия: пользователь узнаёт свою проблему в тегах.
6. **FAQ** — снимает возражения до формы (штатный маркетолог, скорость, KPI).

### CTA-стратегия

- Primary CTA «Оставить заявку» — в header, hero, CTA-блоке, форме.
- Secondary «Бесплатный аудит» — низкий порог входа для сомневающихся.
- Форма минимальна: имя + телефон + согласие (как на текущем сайте).

### Навигация

- Sticky header с полупрозрачным blur — контекст не теряется при скролле.
- На mobile — бургер с `aria-expanded`, закрытие по Escape и при клике на ссылку.
- Skip link «Перейти к основному содержимому» для клавиатуры и скринридеров.

### Форма

- Labels связаны с полями (`for` / `id`).
- `autocomplete` для имени и телефона.
- Checkbox согласия обязателен (`required`, `aria-required`).
- Минимальная высота полей и кнопок: 44px (touch target).

### FAQ

- Нативный `<details>` / `<summary>` — доступен без JS, работает со скринридерами.
- Визуальный индикатор «+» → «×» при раскрытии.

### Партнёры

- Плейсхолдеры под логотипы; при интеграции — реальные SVG/PNG с `alt`-текстом.

## 6. Доступность (WCAG 2.1 AA)

| Критерий | Реализация |
|----------|------------|
| **1.3.1 Info and Relationships** | Семантические теги: `header`, `main`, `nav`, `section`, `footer`, `article` |
| **1.4.3 Contrast** | Палитра проверена (см. таблицу выше) |
| **1.4.4 Resize Text** | rem/em, fluid typography, без фиксированных px для текста |
| **1.4.10 Reflow** | Mobile-first, без горизонтального скролла до 320px |
| **1.4.11 Non-text Contrast** | Границы карточек, focus ring, кнопки ≥ 3:1 |
| **2.1.1 Keyboard** | Все интерактивные элементы доступны с клавиатуры |
| **2.4.1 Bypass Blocks** | Skip link |
| **2.4.2 Page Titled** | `<title>` и `meta description` |
| **2.4.3 Focus Order** | Логичный порядок DOM |
| **2.4.7 Focus Visible** | `:focus-visible` с outline 2px |
| **2.5.5 Target Size** | Кнопки и поля ≥ 44×44px |
| **3.3.2 Labels or Instructions** | Явные labels у всех полей формы |
| **4.1.2 Name, Role, Value** | `aria-label`, `aria-expanded`, `aria-labelledby` |

### Reduced motion

`@media (prefers-reduced-motion: reduce)` отключает анимации и `scroll-behavior: smooth`.

## 8. Следующие шаги (для разработки)

1. Заменить плейсхолдеры партнёров на реальные логотипы.
2. Подключить отправку формы (CRM / Telegram / email).

4. Оптимизировать изображения и подключить favicon.

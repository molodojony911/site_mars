# MARS Agency — визуальный прототип

HTML/CSS макет лендинга [mars-agency.pro](https://mars-agency.pro).

## Запуск

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Семантическая разметка лендинга |
| `css/variables.css` | CSS variables — палитра, типографика, отступы |
| `css/styles.css` | Компоненты и layout (mobile-first) |
| `js/main.js` | Мобильное меню, FAQ, валидация формы |

Подробнее: [`../docs/design.md`](../docs/design.md)

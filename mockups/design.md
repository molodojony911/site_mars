## Карта сценариев

```
/start
 ├─ Загрузить CSV → файл принят → Начать → прогресс → итог + CSV
 │                                    └─ Отменить → «файл не сохранён»
 ├─ Формат файла → Назад
 └─ Данные и приватность → Удалить сейчас / Назад
```

Ошибки (боковые ветки): нет столбца `phone` · лимит 500 · DaData down.

---

## Экраны и тексты (кратко)

| # | Экран | Ключевой текст бота |
|---|--------|---------------------|
| 1 | /start | «👋 Я FraudScore…» + «Пришли CSV со столбцом phone (до 500 строк)…» |
| 2 | Формат | phone · UTF-8 · `,`/`;` · лимит 500 + mono-превью |
| 3 | Загрузка | «Файл принят. Нашёл столбец phone, 342 номера…» |
| 4 | Прогресс | «⏳ Проверяю…» · бар N/M · 🟢/🟡/🔴 · edit_message |
| 5 | Отмена | «Проверка отменена. Обработано 120 из 342, файл не сохранён.» |
| 6 | Итог | саммари + топ-3 high risk (маски) + `fraudscore_report_*.csv` |
| 7 | Ошибки | нет phone / 812>500 / DaData недоступна |
| 8 | Приватность | TTL 24ч · только DaData · /delete · сигналы ≠ доказательство |

## UX-чеклист

- [x] Прогресс через `edit_message`, не flood
- [x] Маскирование номеров в чате (`+7 916 ***-45-67`)
- [x] Лимит 500 строк с понятной ошибкой
- [x] Inline-кнопки ≥ 44px
- [x] WCAG AA контраст на тёмной теме Telegram
- [x] Mobile-first ширина чата ~420px
- [x] Политика хранения 24ч + `/delete`
